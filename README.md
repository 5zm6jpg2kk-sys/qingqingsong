# 清清松 🏆

一个帮助负债人理清财务状况、制定还款计划的智能工具。

## 功能

- 📸 **截图智能导入**：截图花呗/借呗/信用卡账单，自动识别填入
- 📊 **债务仪表盘**：总览负债情况、每日还款目标、清债倒计时
- 💰 **债务管理**：多笔债务统一管理，区分信用卡/网贷/亲友借款
- 📋 **还款规划**：雪球法 vs 雪崩法对比，自动生成逐月还款计划
- 💼 **副业推荐**：根据你的技能匹配合适的日结/周结副业
- 🔐 **隐私保护**：默认隐藏金额，地铁上打开不尴尬

## 使用方式

### 手机
1. 用浏览器打开 `index.html`
2. 微信中发送给自己，点开链接
3. 添加到桌面：浏览器菜单 → 添加到主屏幕

### 电脑
1. 用 Chrome 打开 `index.html`
2. 地址栏右侧会出现安装图标，点击安装

## 技术

- 纯前端单文件，数据存本地，不上传服务器
- PWA 支持，可离线使用
- Chart.js 图表可视化
- Tesseract.js 离线 OCR

## 隐私

所有财务数据仅存储在您设备的浏览器 localStorage 中，绝不经过任何服务器。
